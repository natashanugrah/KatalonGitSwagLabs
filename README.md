Swag Labs (https://www.saucedemo.com/) 
is a demo website that allows users to test and demonstrate automation from Sauce Labs company (https://saucelabs.com/).

My main contribution on this project is to automate these functionalities using testing frameworks like Katalon Studio. 
I already analyzed more than 50 test cases, running on Chrome Driver and some cloud machine until integrated with Jenkins side.

Created by Groovy, HTML, Selenium
